# ژورنال معاملات (Trade Journal) — نسخه Tauri

اپلیکیشن دسکتاپ ویندوزی مستقل برای ثبت، تگ‌گذاری و مرور معاملات، ساخته‌شده با
**Tauri (Rust) + React**. نسبت به نسخه Electron، حجم نهایی چندین برابر کوچیک‌تر
و مصرف حافظه بسیار کمتر است، و برخلاف نسخه اولیه‌ی مبتنی بر `better-sqlite3`،
دیگر مشکل کامپایل native با Visual Studio وجود ندارد چون از `rusqlite`
(با فیچر `bundled`) در سمت Rust استفاده شده که SQLite را خودش کامپایل می‌کند.

## ساختار پروژه

- `src/` — فرانت‌اند React (فرم ثبت سه‌لایه، داشبورد، تقویم، تنظیمات)
- `src-tauri/` — بک‌اند Rust (دیتابیس SQLite، محاسبات، کامندهای Tauri)
- `src-tauri/src/db.rs` — منطق کامل CRUD و آمار (win rate، profit factor، equity curve)
- `src-tauri/src/lib.rs` — لایه کامندهای Tauri که فرانت با آن‌ها ارتباط می‌گیرد

## پیش‌نیازها

1. **Node.js** نسخه ۱۸ به بالا
2. **Rust** — نصب از [rustup.rs](https://rustup.rs)
3. روی ویندوز: **Microsoft C++ Build Tools** (فقط برای کامپایل Rust لازم است،
   نه برای npm). موقع نصب Rust با rustup، اگر Build Tools نصب نباشد، rustup
   خودش لینک نصب را نشان می‌دهد.

## نصب و اجرا (حالت توسعه)

```bash
npm install
npm run tauri dev
```

## ساخت فایل exe نهایی

```bash
npm run tauri build
```

فایل نصبی (`.exe` یا `.msi`) در مسیر زیر ساخته می‌شود:

```
src-tauri/target/release/bundle/nsis/
```

## ساخت خودکار exe با GitHub Actions

هر بار که به شاخه main پوش کنی، یک workflow خودکار (`.github/workflows/build.yml`)
روی سرورهای ویندوزی گیت‌هاب اجرا می‌شود و فایل exe را می‌سازد. از تب Actions
ریپو می‌توانی artifact نهایی را دانلود کنی — بدون نیاز به نصب Rust روی سیستم خودت.

## آیکون اپلیکیشن

اگر یک فایل لوگوی 1024x1024 داری، این دستور همه سایزهای لازم را می‌سازد:

```bash
npx tauri icon path/to/logo.png
```

## ساختار داده‌ای پیاده‌شده

هر معامله شامل سه لایه است:

1. **پلن پیش از معامله** — دلیل ورود، وضعیت بازار، سطح اطمینان، R:R برنامه‌ریزی‌شده
2. **اجرا** — قیمت ورود/خروج، حجم، استاپ/تارگت، کارمزد، محاسبه خودکار سود/زیان و R:R واقعی
3. **روانشناسی و ریویو** — احساس ورود/خروج، پایبندی به پلن، تگ اشتباه، درس گرفته‌شده

## ویژگی‌ها

- داشبورد آماری: Win Rate، Profit Factor، میانگین سود/زیان، Max Drawdown، Equity Curve
- تقویم معاملاتی رنگی (سبز/قرمز بر اساس سود روزانه)
- فیلتر و جستجوی معاملات
- خروجی CSV از تمام معاملات
- تنظیمات سرمایه اولیه و واحد پول
- ذخیره کامل و محلی داده‌ها؛ بدون اتصال به هیچ سروری

## محل ذخیره دیتابیس

```
Windows: %APPDATA%\com.tradejournal.app\trade_journal.db
```

## توسعه بیشتر

می‌توان قابلیت‌های زیر را در آینده اضافه کرد: آپلود واقعی اسکرین‌شات چارت،
ایمپورت CSV از بروکر، گزارش هفتگی خودکار، پشتیبان‌گیری ابری اختیاری.
